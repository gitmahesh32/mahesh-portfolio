# Mahesh Rathore - Portfolio

Personal portfolio website built with:

- Vue 3
- TypeScript
- Tailwind CSS
- Vite

## Features

- About Me
- Skills
- Experience
- Projects
- Services
- Contact

## Tech Stack

Frontend:
- Vue 3
- TypeScript
- Tailwind CSS

Backend:
- PHP
- Laravel

Database:
- MySQL

## Installation

npm install

## Development

npm run dev

## Production Build

npm run build
